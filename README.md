# CYBER//UI — киберпанк-интерфейс для Minecraft 26.3

Чёрно-жёлто-красный киберпанк-редизайн **только меню и интерфейсов**. Мир,
блоки, мобы и почти весь игровой HUD (сердца, опыт, прицел) остаются ванильными;
из HUD перерисованы хотбар и полоски здоровья боссов.

## Установка (без модов)

1. Скачай готовый пак: [CYBER-UI-26.3.zip](https://github.com/f11htq/remake-minecraft-interface-resource-pack-/raw/claude/charming-maxwell-r48eep/CYBER-UI-26.3.zip)
2. Положи файл (не распаковывая) в папку `resourcepacks` игры.
   Открыть её проще всего из игры: Настройки → Пакеты ресурсов → «Открыть папку пакетов».
3. Включи **CYBER//UI** в списке пакетов и нажми «Готово».

Больше ничего не нужно: пак работает на чистой 26.3, моды не требуются.
С модами (Fabric, Sodium и т.д.) он тоже совместим.

## Мод CYBER//UI (необязательно, Fabric 26.3)

Ресурс-пак меняет внешний вид, а мод добавляет то, что ресурс-паком сделать нельзя:

- кнопки главного меню в колонке слева, по очереди выезжают при открытии;
- логотип слева, справа выезжает HUD-панель «SYS//STAT», внизу сигнальная полоса;
- панорама «Бледный сад» в киберпанк-обработке, даже без ресурс-пака;
- анимированный хотбар: при входе в мир и после возрождения он выезжает снизу,
  слоты по очереди «загружаются» за скан-линией; рамка выбора скользит между
  слотами с послесвечением и красно-голубым расслоением, уголки-прицел
  защёлкиваются на слоте; выбранный предмет приподнимается, над ним мигает
  номер слота; подобранный предмет подсвечивает слот вспышкой, почти сломанный
  инструмент пульсирует красной рамкой; название предмета печатается на
  табличке в цвете его редкости; по нижней кромке бежит поток данных;
- анимация перехода («бронедверь») на экранах меню;
- плавные инвентари в игре: рамка наведения скользит от слота к слоту, панель
  мягко появляется при открытии, в креативе плавный ползунок прокрутки и
  переход при смене вкладки;
- уникальные полоски здоровья боссов: дракон, визер, рейд, а также Хранитель,
  железный голем, разоритель, вызыватель и страж (у них
  полоска появляется, когда они получают урон рядом с тобой). След урона,
  тряска при ударе, глитчи, частицы, а при победе — объёмные буквы **GG**; полоска дракона перед этим
  взрывается на осколки с глитчами и ударной волной;
- в портал выхода из Края с неба бьёт луч и пронзает остров насквозь,
  потом раскрывается во всю бедроковую обводку и остаётся сверху и снизу;
  в момент удара — ударная волна, раскат грома и землетрясение;
- свой экран загрузки вместо красного Mojang, **в том числе при самом первом запуске**:
  логотип, жёлтая шкала прогресса, проценты, бегущие строки.

Установка: скачай [cyber-ui-mod-26.3.jar](https://github.com/F11htq/Remake-Minecraft-Interface-resource-pack-/releases/download/mod-latest/cyber-ui-mod-26.3.jar)
и положи в папку `mods`. Нужны Fabric Loader 0.20+ для 26.3 и Java 25 (Fabric API не обязателен).
FancyMenu и Drippy Loading Screen с этим модом не нужны: удали их, чтобы они не конфликтовали.

Мод собирается автоматически через GitHub Actions из папки `mod/` при каждом изменении
(Java 25, Gradle 9.8). CI заодно проверяет, что все методы игры, к которым цепляются
mixin-ы, существуют в 26.3 (`.github/scripts/check-mixin-targets.sh`).

## Что меняет ресурс-пак

| Элемент | Эффект |
|---|---|
| Кнопки | Тёмные плашки со срезанным углом и жёлтым маркером; при наведении — красная подсветка, жёлтая рамка и глитч-вспышки |
| Слайдеры | Шкала с делениями, ручка в «сигнальную» полоску, при наведении полоски бегут |
| Поля ввода | При фокусе — жёлтая рамка и мигающие красные уголки |
| Чекбоксы, вкладки, скроллбары | В том же стиле |
| Подсказки (tooltip) | Чёрное «стекло» со сканлайнами, жёлтая рамка, редкий глитч цвета |
| Наведение на слот | Прицельные уголки «захватывают» слот |
| Инвентарь и все контейнеры | Тёмные панели, жёлто-красная линия сверху, жёлтые заголовки, ванильная раскладка |
| Креатив, книга рецептов, достижения | В той же палитре |
| Фон меню, разделители | Почти чёрный фон со сканлайнами, жёлто-красные разделители |
| Полоски здоровья боссов | Тёмный корпус со срезанными углами, неоновое заполнение с бегущими полосками (все 7 цветов), засечки-деления |
| Логотип | Жёлто-красный с хроматическим «двоением» |
| Хотбар | Бронированная тёмная полоса с колодцами слотов, неоновая кромка с бегущим бликом, рамка выбора-прицел с «дышащим» свечением |
| Панорама главного меню | Панорама «Бледный сад» (1.21.4) в ночной киберпанк-гамме, сканлайны, виньетка |
| Экран загрузки | Чёрный фон вместо красного (при перезагрузке ресурсов) |

Заголовки контейнеров игра рисует тёмно-серым. Шейдер
`shaders/core/rendertype_text.vsh` перекрашивает **только этот цвет и только
на экранах меню** в жёлтый; текст в мире не затрагивается.

## Ограничения

- Без мода экран загрузки остаётся красным: в 26.3 его фон задаётся кодом
  игры, а не шейдером. Ресурс-пак затемняет только плавные переходы в начале и в
  конце загрузки. С модом экран загрузки полностью свой, в том числе при запуске.
- Без мода хотбар просто перерисован: скольжение рамки, загрузка слотов,
  табличка с названием и остальные анимации хотбара есть только в моде.
- Расположение кнопок в меню ресурс-пак не меняет: это задаётся кодом игры.
- Ресурс-пак не может менять скорость открытия экранов. Плавность дают
  анимированные текстуры.

## Пересборка

Все текстуры генерируются скриптами (нужен Python 3, Pillow и NumPy):

```bash
pip install pillow numpy
python3 tools/build_pack.py --vanilla <путь к assets/minecraft/textures/gui из клиента 26.3>
python3 tools/build_panoramas.py --source <папка с panorama_0..5.png из клиента 1.21.4>
python3 tools/make_zip.py        # собирает CYBER-UI-26.3.zip
python3 tools/build_mod_assets.py [--panoramas <папка с подпапкой 1.21.4>]  # текстуры мода
```

Цвета задаются в начале `tools/build_pack.py`. Исходные ванильные текстуры в
репозиторий не входят: скрипты берут их как шаблон, а в репозиторий попадают
только перекрашенные версии (контейнеры, логотип, панорама).
