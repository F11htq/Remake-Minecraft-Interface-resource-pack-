# Nebula UI — ресурс-пак для Minecraft 1.21.4

Тёмный «неоновый» редизайн **только меню и интерфейсов**. Мир, блоки, мобы и
игровой HUD (хотбар, сердца, опыт, прицел) остаются ванильными.

## Что меняется

| Элемент | Эффект |
|---|---|
| Кнопки | Тёмные с градиентом; при наведении — плавно переливающаяся неоновая рамка |
| Слайдеры | Тёмная дорожка, градиентная ручка, пульсация при наведении |
| Поля ввода | При фокусе — анимированная подсветка рамки |
| Чекбоксы, вкладки, скроллбары | В едином стиле, с анимацией при наведении |
| Подсказки (tooltip) | Полупрозрачный фон и «перетекающая» градиентная рамка |
| Наведение на слот | Мягкое пульсирующее свечение вокруг слота |
| Инвентарь и все контейнеры | Тёмные панели, неоновая линия сверху, сохранена ванильная раскладка |
| Креатив, книга рецептов, достижения | Перекрашены в ту же палитру |
| Фон меню, разделители | Тёмно-синий фон с узором, неоновые разделители |

Заголовки контейнеров («Инвентарь», «Сундук»…) игра рисует тёмно-серым — на
тёмном фоне их не видно. Небольшой шейдер (`shaders/core/rendertype_text.vsh`)
перекрашивает **только этот цвет и только на экранах меню**, текст в мире не
затрагивается.

> Скорость открытия экранов и прочую логику интерфейса ресурс-пак изменить не
> может — плавность достигается анимированными текстурами с интерполяцией
> кадров.

## Установка

1. Скачай репозиторий архивом (или собери zip из `pack.mcmeta`, `pack.png` и
   папки `assets`).
2. Положи архив в `.minecraft/resourcepacks`.
3. В игре: Настройки → Пакеты ресурсов → включи **Nebula UI**.

## Пересборка текстур

Все текстуры генерируются скриптом `tools/build_pack.py` (нужен Python 3 и
Pillow). Цвета и анимации задаются в начале скрипта.

```bash
pip install pillow
python3 tools/build_pack.py --vanilla <путь к assets/minecraft/textures/gui из клиента 1.21.4>
```

Ванильные текстуры используются только как шаблон раскладки контейнеров и в
репозиторий не входят.
