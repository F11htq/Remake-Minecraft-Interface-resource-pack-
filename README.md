# CYBER//UI — киберпанк-интерфейс для Minecraft 1.21.4

Чёрно-жёлто-красный киберпанк-редизайн **только меню и интерфейсов**. Мир,
блоки, мобы и игровой HUD (хотбар, сердца, опыт, прицел) остаются ванильными.

Комплект состоит из двух частей:

1. **Ресурс-пак** (`pack.mcmeta`, `pack.png`, `assets/`). Работает сам по себе, без модов.
2. **Настройки FancyMenu** (`fancymenu-setup/`). Новое анимированное главное меню
   и свой экран загрузки. Нужны моды.

## Что меняет ресурс-пак

| Элемент | Эффект |
|---|---|
| Кнопки | Тёмные плашки со срезанным углом и жёлтым маркером; при наведении — красная подсветка, жёлтая рамка и глитч-вспышки |
| Слайдеры | Шкала с делениями, ручка в «сигнальную» полоску, при наведении полоски бегут |
| Поля ввода | При фокусе — жёлтая рамка и мигающие красные уголки |
| Чекбоксы, вкладки, скроллбары | В том же стиле |
| Подсказки (tooltip) | Чёрное «стекло» со сканлайнами, жёлтая рамка, редкий глитч цвета |
| Наведение на слот | Прицельные уголки «захватывают» слот |
| Инвентарь и все контейнеры | Тёмные панели, жёлто-красная линия сверху, жёлтые заголовки, ванильная раскладка |
| Креатив, книга рецептов, достижения | В той же палитре |
| Фон меню, разделители | Почти чёрный фон со сканлайнами, жёлто-красные разделители |
| Логотип | Жёлто-красный с хроматическим «двоением» |
| Панорама главного меню | Ванильная панорама 1.21.4 в ночной киберпанк-гамме, сканлайны, виньетка |
| Экран загрузки | Чёрный фон вместо красного (при перезагрузке ресурсов) |

Заголовки контейнеров игра рисует тёмно-серым. Шейдер
`shaders/core/rendertype_text.vsh` перекрашивает **только этот цвет и только
на экранах меню** в жёлтый; текст в мире не затрагивается.

## Что добавляет FancyMenu

**Главное меню**
- официальные вращающиеся панорамы Minecraft из 10 версий: подводный мир (1.13),
  деревня (1.14), пчёлы (1.15), Незер (1.16), пещеры (1.17), горы на закате (1.18),
  мангровое болото (1.19), вишнёвая роща (1.20), Пробные камеры (1.21) и Бледный сад (1.21.4);
- при каждом открытии меню выбирается случайная панорама;
- все панорамы перекрашены в ночную киберпанк-гамму: тёмно-синие тени, малиновые
  полутона и жёлтые блики, сверху сканлайны и красное свечение снизу;
- логотип с глитч-вспышками и мерцанием, плавно появляется;
- кнопки в колонке слева, по очереди выезжают при открытии меню;
- справа выезжает HUD-панель «SYS//STAT» с бегущими данными;
- внизу анимированная сигнальная полоса.

**Анимация переходов**
При открытии главного меню, настроек, выбора мира и сервера, меню паузы и
других экранов меню экран закрывает «бронедверь» со сканлайнами. Она уезжает
вверх, а её светящийся край с помехами проходит по экрану. Инвентари и
контейнеры не затрагиваются.

**Экран загрузки** (Drippy Loading Screen, в том числе при запуске игры)
- фон-сетка, по которой бежит сканирующая полоса;
- логотип с глитчем «падает» сверху;
- жёлтая полосатая шкала с реальным прогрессом загрузки, крутящийся индикатор и проценты;
- бегущие строки «LOADING TEXTURES… LINKING SHADERS…», сигнальные полосы сверху и снизу.

## Установка

### 1. Ресурс-пак
1. Заархивируй в zip `pack.mcmeta`, `pack.png` и папку `assets`. Эти файлы
   должны лежать **в корне архива**, без папки-обёртки.
2. Положи архив в `.minecraft/resourcepacks`.
3. В игре: Настройки → Пакеты ресурсов → включи **CYBER//UI**.

### 2. Моды (для главного меню и экрана загрузки)
Нужен Fabric (или NeoForge/Forge) для 1.21.4 и моды из Modrinth / CurseForge:

| Мод | Версия |
|---|---|
| Fabric API (только для Fabric) | для 1.21.4 |
| FancyMenu | 3.7 или новее для 1.21.4 |
| Konkrete | для 1.21.4 (зависимость FancyMenu) |
| Melody | для 1.21.4 (зависимость FancyMenu) |
| Drippy Loading Screen | 3.0 или новее для 1.21.4 |

Скопируй папку `fancymenu-setup/config` в `.minecraft/` (с объединением папок).
Должны появиться:

```
.minecraft/config/fancymenu/customization/cyber_ui_title_screen.txt
.minecraft/config/fancymenu/customization/cyber_ui_title_bg_*.txt      (10 панорам)
.minecraft/config/fancymenu/customization/cyber_ui_transition.txt
.minecraft/config/fancymenu/customization/cyber_ui_loading_screen.txt
.minecraft/config/fancymenu/assets/cyber_ui/...
.minecraft/config/fancymenu/panoramas/cyber_*/...
.minecraft/config/fancymenu/customizablemenus.txt
```

`customizablemenus.txt` включает кастомизацию FancyMenu для главного меню и
экранов меню: без этого FancyMenu не применяет раскладки. Если меню всё равно
выглядит по-старому, открой его и в верхней панели FancyMenu выбери
«Кастомизация → Включить кастомизацию для этого экрана».

Раскладки можно дальше править во встроенном редакторе FancyMenu. Чтобы
убрать какую-то панораму из случайного выбора, удали её файл `cyber_ui_title_bg_*.txt`. Чтобы
выключить анимацию переходов, удали `cyber_ui_transition.txt`.

## Ограничения

- Без Drippy самый первый экран загрузки при запуске остаётся красным: он
  появляется до подключения ресурс-паков.
- Ресурс-пак не может менять скорость открытия экранов. Плавность дают
  анимированные текстуры, а в главном меню — анимации FancyMenu.

## Пересборка

Все текстуры и раскладки генерируются скриптами (нужен Python 3 и Pillow):

```bash
pip install pillow
python3 tools/build_pack.py --vanilla <путь к assets/minecraft/textures/gui из клиента 1.21.4>
python3 tools/build_panoramas.py --source <папка с подпапками 1.13 … 1.21.4, в каждой panorama_0..5.png>
python3 tools/build_fancymenu.py
```

Цвета задаются в начале `tools/build_pack.py`. Исходные ванильные текстуры в репозиторий не входят: скрипты берут их
как шаблон, а в репозиторий попадают только перекрашенные версии (контейнеры,
логотип, панорамы).
